# 拾物 Shelf — 个人购物收藏管理器

一个可直接部署的响应式 HTML/CSS/JavaScript 起始项目。默认支持本机浏览器保存；完成 Supabase 配置后可启用云端同步与管理员登录。

## 当前已实现

- 一次粘贴多个商品 URL（每行一个）
- 去重与 URL 基本校验
- 根据链接域名/关键词给出简单分类建议（不是 AI 识别）
- 合集新建、重命名、描述编辑、删除；删除合集时商品移至待整理
- 商品名称、价格、货币、店家、分类、链接、图片 URL、个人评分、购买状态、评价/风评摘要、备注可编辑
- 按合集、待整理、购物清单筛选；搜索、排序
- 本地 localStorage 保存、JSON 导入/导出备份
- 可选 Supabase Auth + Postgres 同步的前端接口

## 当前限制（请先看）

1. **自动导入并不等于自动抓取商品信息。** 纯浏览器 HTML 不能可靠地读取所有购物平台页面：CORS、反爬、登录墙、页面结构、地区和平台规则都会阻挡抓取。本版导入 URL 后会用网址生成一个初始标题，并尝试给出分类建议；价格、商品图和真实评论需要手动补充。
2. 评论/风评功能目前是可编辑的摘要字段，不会伪装成已抓取的真实评论。若要自动收集，需要针对具体平台接入官方 API、合规数据源或经授权的后端适配器，并显示来源和抓取时间。
3. Supabase 云端同步必须先配置数据库、RLS 和 Auth。未完成设置前数据只在当前浏览器，清除浏览器数据会丢失。请先导出备份。
4. 这是单管理员 MVP。生产使用前，建议把公开读取和管理员写入权限策略在 Supabase SQL Editor 中测试；不要将 service_role 密钥放在前端。
5. 目前商品图片字段使用图片 URL；本版没有做图片文件直接上传，也没有在商品卡片上调用通用网页抓取服务。可在下一阶段加入 Supabase Storage 图片上传及平台适配器。
6. 云端配置在当前浏览器 localStorage 中。若你不希望在共享设备保留配置，请退出登录并清理浏览器站点数据。

## 本地预览

直接用浏览器打开 `index.html` 通常可以预览基本功能。推荐用静态服务器运行（例如 VS Code Live Server），以获得更稳定的登录回调行为。

## 部署到 Cloudflare Pages

1. 将整个文件夹打包为 ZIP，或将文件拖入 Cloudflare Pages Direct Upload。
2. 确保 `index.html`、`styles.css`、`app.js` 在部署根目录。
3. 部署后先测试本机模式；每次更新后重新部署。

## 配置 Supabase 云端同步

### A. 创建项目

1. 在 https://supabase.com/ 创建项目。
2. 在 Project Settings / API（或 Connect 面板）复制 Project URL 和公开的 anon/publishable key。
3. **不要复制 service_role / secret key 到网站。**

### B. 创建表和权限

1. 打开 Supabase Dashboard → SQL Editor。
2. 运行本项目的 `supabase_schema.sql`。
3. 检查 `folders`、`products` 表都启用了 RLS。
4. 在 Authentication → URL Configuration 中添加你部署后的网址到 Site URL / Redirect URLs。
5. 创建你自己的 Auth 用户。建议关闭普通用户自助注册，仅保留管理员账户。
6. 为 `product-images` 创建 Storage bucket（本版目前保存图片 URL，不直接上传文件）。

### C. 连接网站

1. 打开部署后的网站，点右上角设置。
2. 填入 Project URL、公开客户端 key 和你的管理员邮箱。
3. 点“连接云端”，再点“发送登录链接”。
4. 打开邮箱中的登录链接，返回网站。
5. 登录后测试新增、编辑、删除是否成功同步；在另一台设备打开同一个网址并登录，可读取云端数据。

### D. 重要的权限说明

当前 SQL 策略允许任何人读取 `is_public = true` 的行；写入要求 `auth.uid() = user_id`。前端只会把登录用户 ID 写入行。上线前请确认只有你有 Auth 账户，并使用另一个未登录浏览器测试：应能查看公开商品，但不能写入。

**注意：当前前端的云端同步逻辑主要面向单一管理员自己的资料库。** 如果你要公开展示与云端读取全部数据，建议下一阶段再加专用只读展示模式和更严格的管理员 ID 限制，避免混淆访客视图与管理员编辑状态。

## 建议的下一阶段

- 直接上传图片到 Supabase Storage
- 真正的公开访客只读模式与固定管理员 ID 的写入策略
- 商品链接元数据提取 Edge Function（逐个平台适配；不要随意部署无域名限制的 URL 抓取代理）
- 对 Amazon、淘宝、京东、品牌独立站等分别接入可用且合规的数据来源
- 评论来源、时间戳、样本量、正负面摘要与置信度
- 多币种汇率换算、价格历史与降价提醒
